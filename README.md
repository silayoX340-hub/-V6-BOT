A powerful WhatsApp multi-device bot with YouTube downloader, server status, stickers, AI chat, group management, and many more commands.

## ✨ Features
- 🎵 **YouTube audio/video download** (`.play`, `.ytv`, `.ytmp3`)
- 📊 **Server status panel** (`.status` - CPU/RAM/uptime)
- 🎨 **Sticker maker** (`.sticker`, `.toimg`)
- 🤖 **AI chat** (`.ai`)
- 👥 **Group management** (`.tagall`, `.kick`, `.promote`, `.demote`)
- 🚪 **AFK system** (`.afk`)
- 🔧 **Owner commands** (`.join`, `.leave`)
- ❌ **Delete bot messages** (`.delete`)
- ℹ️ **Group info** (`.groupinfo`)
- 🏓 **Ping** (`.ping`)
